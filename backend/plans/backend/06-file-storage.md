# Backend Plan 06 — File Storage

## Overview

Implement Cloudinary integration for resume file uploads (PDF/DOCX), file validation, and PDF generation for cover letter exports using pdfkit. This module handles all file operations: upload, storage, retrieval, and document generation.

## File Upload Interceptor

### `file-upload.interceptor.ts`

```typescript
import { FileInterceptor } from '@nestjs/platform-express';
import { BadRequestException } from '@nestjs/common';

export const ResumeUploadInterceptor = FileInterceptor('file', {
  limits: {
    fileSize: 10 * 1024 * 1024, // 10MB
  },
  fileFilter: (req, file, cb) => {
    const allowedMimes = [
      'application/pdf',
      'application/vnd.openxmlformats-officedocument.wordprocessingml.document',
    ];
    if (!allowedMimes.includes(file.mimetype)) {
      cb(new BadRequestException('Only PDF and DOCX files are allowed'), false);
    } else {
      cb(null, true);
    }
  },
});
```
